# Caesar Cipher 

A command-line tool that encodes or decodes text messages using the classic Caesar cipher, shifting each letter by a user-defined amount.

## Features
- Encode or decode any message
- Custom shift amount
- Non-letter characters stay unchanged
- Keeps running until you choose to quit

## Usage
python main.py

Enter `encode` or `decode`, type your message, enter a shift number, and get the result instantly.
